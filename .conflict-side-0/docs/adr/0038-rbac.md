# ADR 0038: RBAC — Local Role-Based Access Control (M71)

## Status
Accepted — grill Q1 (core + CLI + desktop, collaboration deferred)

## Context
Enterprise §58.5 needs RBAC without cloud. Policy handles workflow steps, but not user roles.

## Decision
`internal/rbac` (M71): `RBAC{Roles,UserRoles}` + `Role{Name,Permissions}` + `DefaultRBAC` (admin `*`, editor 6 perms, viewer 2 perms) + `Validate` + `Can`/`Enforce`/`ListRoles` + `Load`/`Save`/`DefaultPath` (`.reqly/rbac.yaml` 0600); CLI `reqly rbac list/check` + desktop `RBACList/Check/Get`.

## Consequences
Q1: In-memory + file, not LDAP — simple local RBAC.
Q2: Collaboration deferred — RBAC does not handle shared workspaces.
