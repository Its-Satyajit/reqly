Reqly — Git-Native UI

One complete, navigable application covering the full product surface: collections, REST / GraphQL / gRPC / WebSocket / SSE / SOAP clients, environments across 6 scopes, full-text history, reqly.* scripting, test runner, bulk & pagination runners, OpenAPI explorer, import/export with the M42 report, code generation, mock servers, breaking-change diff, Git worktree panel, and settings. Press ⌘K inside for the command palette and state simulations.

Atlas Dark — layered graphite, floating command surface

Deep layered dark theme with floating pill bars, a rail that unfolds its labels on hover, a slide-over context panel, and a console dock that surfaces on hover. Source-control state lives inside the collections sidebar; every view — from the REST builder to the merge resolver — is fully interactive with realistic loading, empty, error and conflict states.
